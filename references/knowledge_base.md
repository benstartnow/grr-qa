## 一、成功投资股市的五项原则（第1章）

**卡片 1.1 做好功课**
- 定义：买股票前像准备收购整家公司一样做尽职调查。
- 要点：读年报（10-K/10-Q）、读"管理层讨论与分析 MD&A"、读脚注、读竞争对手年报做对比；亲自体验产品/服务。
- 来源：第1章·投资者清单

**卡片 1.2 寻找具有强大竞争优势的公司（护城河）**
- 定义：好生意与烂生意的区别不在行业增长率，而在"能不能守住利润不被竞争者抢走"。
- 要点：找"能长期维持高资本回报率"的，而非"增长最快"的。（详见第三章护城河）
- 来源：第1章（全书灵魂命题）

**卡片 1.3 拥有安全边际**
- 定义：即使找到好公司，买贵了也会变成烂投资；只在价格明显低于保守估算的内在价值时出手。
- 要点：用多种估值法交叉验证（第9–10章）；大部分时间应等待和持币，而非天天满仓。
- 来源：第1章

**卡片 1.4 长期持有**
- 定义：减少交易频率 = 减少手续费/税损对复利的侵蚀；企业创造价值需要时间，护城河回报是多年累积的。
- 要点：频繁买卖是"失败者的游戏"；理想持有到基本面变坏为止。
- 来源：第1章

**卡片 1.5 知道何时卖出**
- 定义：卖出决策 = 追踪基本面，而非看股价涨跌。
- 卖出情形：①买入时判断错了（认错止损）②基本面实质恶化 ③股价远超内在价值 ④发现明显更好的机会 ⑤仓位过重需再平衡。
- 不卖理由：股价跌了（≠公司变差）、股价涨了（≠公司变好）——这两件事本身不构成买卖信号。
- 来源：第1章·投资者清单

## 二、七个应当避免的错误（第2章）

**卡片 2.1 虚幻的目标**
- 试图"发现下一个微软/亚马逊"赚百倍 = 买彩票不是投资。追逐热门 IPO、概念股、题材股。
- 正确心态：找确定性高的合理回报，而非全垒打。

**卡片 2.2 相信"这次与以往不同"**
- 每轮泡沫咒语都是"旧规则不适用了"，但人性不变、估值规律不变。
- 案例：2000 科网泡沫"点击率代替盈利"、2008"房价不会跌"。当有人告诉你"旧估值框架失效"，警报该响。

**卡片 2.3 陷入对公司产品的偏爱**
- "我超爱这家公司的产品 → 所以它一定是好股票"是致命跳跃。伟大的产品 ≠ 赚钱的生意。
- 自问：这是个有吸引力的生意吗？如果买得起，我会买下整个公司吗？

**卡片 2.4 在市场下跌时惊慌失措**
- 价格下跌 ≠ 价值下降。若功课确认了内在价值，下跌反而是加仓区。
- 最悲观时刻往往是最好的买点——前提是分析没错。恐慌抛售把暂时性波动变成永久性本金损失。

**卡片 2.5 试图选择市场时机**
- 无人能持续精准抄底逃顶。错过股市最好的几天（常在暴跌后）摧毁长期回报。
- 解法：定期再平衡 + 按估值分批买入，而非预测大盘。

**卡片 2.6 忽视估值**
- 哪怕好公司，买贵了 = 烂回报。估值是投资过程中最重要的部分。
- 案例：可口可乐/苹果，2015 年买和 2021 年底买结局完全不同。

**卡片 2.7 依赖盈利数据作分析**
- 会计"净利润"可被折旧年限、费用资本化、一次性项目等修饰；现金流才是照妖镜。
- 核心警句："利润是观点，现金是事实"。

## 三、竞争优势（经济护城河，第3章，全书核心）

**卡片 3.1 护城河四步诊断法**
- 第一步·评估收益性：它有超额利润的证据吗？看历史（最好10年，最少5年），不是看一年。指标见第十一节阈值。
- 第二步·利润的来源：为什么它能挡住竞争者？（护城河真实来源见 3.2）
- 第三步·它能持续多久（宽度）：见 3.3。
- 第四步·行业分析：这是个好池塘吗？见 3.5。

**卡片 3.2 护城河的真实来源（四种 + 晨星第五因素）**
- ① 无形资产：品牌溢价（消费者愿为多付钱）+ 专利/法定许可（法律保护排他）。
  - 品牌要看"是否增加消费者购买意愿/降低搜索成本"，而非知名度。索尼知名度高但难溢价；蒂芙尼/可口可乐能溢价。
  - 专利有保质期且易被挑战；大型专利组合（如高通）才算真壁垒；特许经营权（赌场牌照、垃圾填埋许可）最坚固。
- ② 高转换成本：客户换供应商成本太高（数据迁移、培训、业务中断风险）→ 被"锁住"。
  - 案例：企业软件（SAP/Oracle/Workday）、Windows 生态、企业云基础设施、工业螺栓供应商 Fastenal。
- ③ 网络效应：每个新用户让产品对所有老用户更有价值 → 赢家通吃。
  - 案例：微信、Visa/Mastercard 支付网络、交易所、Google 搜索。
  - 陷阱：区分"交互型网络"（eBay，极难攻破）与"辐射型网络"（西联汇款点对点，易被逐个击破）。网络建立在生态而非特定技术上才最稳。
- ④ 成本优势：规模经济 + 独特工艺/地理位置。
  - 案例：沃尔玛采购规模、台积电制造规模、大宗商品低成本生产商。
  - 两种：流程优势（易被模仿，如早期西南航空）vs 规模优势（极难颠覆，如 UPS/FedEx 物理网络密度）。
- ⑤ 有效规模（efficient scale，晨星后来补充的第五因素）：在规模有限的市场中，被少数企业高效占领，新进入者难立足。
  - 注：多尔西原书列四种（无形资产/转换成本/网络效应/成本优势），晨星现行框架补充"有效规模"为第五来源。

**卡片 3.3 护城河宽度（持续时间）**
- 深度：公司能赚多少钱（ROE/利润率多厚）。
- 宽度：能保持多久。
  - 很短（1–3年）：纯靠一款热门产品/技术领先，无配套壁垒。
  - 几年：有专利保护期、或阶段性品牌优势，但到期/竞争会侵蚀。
  - 很多年（10年+）：多重壁垒叠加（品牌+规模+转换成本+网络效应），行业本身不太可能被颠覆。
- 晨星评级口径：宽护城河 = 防御可维持 20 年+；窄护城河 = 至少 10 年；无护城河 = 无持久优势。

**卡片 3.4 伪护城河（常见陷阱）**
- 高市场份额 ≠ 护城河（GM、康柏"大而不强"）。
- 优质产品 ≠ 护城河（Krispy Kreme 甜甜圈、Heelys 暴走鞋；纯技术优势极短暂）。
- 卓越管理层 ≠ 护城河（个人充满不确定性、易流动；是加分项非持久壁垒）。
- 技术领先 ≠ 护城河（可被反向工程/迭代超车；真正壁垒是技术之上的标准锁定或生态）。
- 快速检验：定价权。能每年涨价 2–3% 且客户不离弃，通常才有真护城河；突然"不涨价回馈客户"往往是护城河被填平的信号。

**卡片 3.5 行业结构分析（好池塘吗）**
- 好行业特征：适度自然高壁垒 + 缓慢变化 + 有定价权；营业毛利率高于 25% 通常表明有吸引力。
- 差行业特征：价格战常态化、产品同质化、高固定成本迫使所有人拼命生产、技术路线不确定。
- 经典差行业：航空业（巨大资本开支、无差异化、价格战、高经营杠杆）。
- 判断：好行业不如好格局，格局决定行业整体盈利上限。

## 四、财务报表（第4–5章）

**卡片 4.1 三表关系（核心）**
- 资产负债表 = 存量（某一时点快照）：资产 − 负债 = 所有者权益。
- 利润表 = 流量（一段时期）：收入 − 费用 = 净利润（权责发生制）。
- 现金流量表 = 流量（真金白银）：经营/投资/筹资三块。
- 联动铁律：利润好看但现金没进来 = 应收堆积 = 危险信号。永远交叉验证利润表与现金流量表。

**卡片 4.2 资产负债表要点**
- 流动资产：现金够扛周期？应收增速 >> 营收增速（寅吃卯粮）？存货增速 >> 营收增速（滞销积压）？
- 商誉：异常膨胀 = 激进并购标志。研发资本化比例是否过高？
- 负债：利息覆盖倍数 = EBIT/利息费用，一般 >5× 较安全；资产负债率行业差异大，但趋势比绝对值重要（债务是否悄悄爬升）。

**卡片 4.3 利润表要点**
- 毛利率趋势 = 定价权 + 成本控制综合体现（下滑 = 竞争加剧或成本失控）。
- 营业利润率（扣 SG&A 后）比净利率更干净（排除利息/税率/非经常项目噪音）。
- 非经常性损益：看持续经营利润，非 GAAP 净利润。

**卡片 4.4 现金流量表（多尔西最看重）**
- 经营活动现金流 CFO：最核心，生意本身吐不吐现金；健康公司 CFO > 净利润。
- 投资活动 Capex：自由现金流 FCF = CFO − Capex。
- 筹资活动：发股/回购/借债/分红——看回报股东还是不断吸血。
- 结论性忠告：净利润年年涨但经营现金流年年差/为负 → 利润很可能是"纸面富贵"。

## 五、公司分析——基础（第6章）

**卡片 5.1 成长性（问对问题）**
- 问：增长来自哪里？（内生需求 vs 提价 vs 并购 vs 会计手法）可持续吗？需要多少资本投入？
- 关键洞察：靠并购堆出的增长价值有限（收购方常付过高溢价、整合风险大）；销售额增长但利润率压缩 = 用降价换量，护城河反变弱。
- 慢而稳的复利（ROE 15%+，再投资部分利润）> 爆发性但不可持续的增长。
- 警示：盈利增长长期超过销售收入增长，可能是"人造增长"信号（从停滞销售中挤压利润）。

**卡片 5.2 收益性（ROE 杜邦分解）**
- ROE = 净利率 × 资产周转率 × 权益乘数（杠杆）。
- 分清：高 ROE 靠真赚钱（前两项）还是靠加杠杆（第三项）？靠杠杆的高 ROE 危险。

**卡片 5.3 财务健康状况**
- 流动比率 = 流动资产/流动负债，经验 >1.5（行业可调）。
- 利息覆盖倍数 >5×。
- 净现金（现金−总债务）为正更好。
- 警惕表外负债（经营租赁资本化前、担保、养老金赤字）。

**卡片 5.4 空头情形（Short the Story）**
- 从反面想：若你是做空者，会攻击公司哪些弱点？
- 常用攻击点：客户集中度高、供应商集中、关键人物风险、应收账款质量、库存周转恶化、或有负债。
- 若这些弱点不存在或无关紧要 → 公司更扎实，利于在艰难时期握紧股票。

## 六、公司分析——管理层（第7章）

**卡片 6.1 管理层评估三维（报酬 / 性格 / 运作）**
- 报酬：看委托代理说明书（Proxy）。薪酬是否与长期业绩挂钩？股权激励行权期够长吗？
  - 红灯：巨额签约奖金、与业绩脱钩天价底薪、给高管放贷、用"调整后非GAAP利润"做唯一 KPI 且调整项越来越大。
- 性格：管理层是否利益输送给亲友？董事会是否有太多 CEO 亲信？是否坦诚面对错误？
- 运作：现任团队任期内的财务表现（高且增长的 ROE/ROA）；是否坚持到底贯彻计划（还是年年宣布新战略却不执行）；信息是否坦率（避而不谈 = 警报）；是否自信（行业低迷仍维持研发支出）；是否灵活抓机遇。
- 核心原则（巴菲特比喻）："好骑师骑好马"——生意本身质量（赛马）通常比管理者能力（骑师）更重要；例外是顶级"资本配置者"（如巴菲特、丹纳赫雷尔斯兄弟），极罕见。
- 警示：核心业务放缓时，平庸管理层常靠乱收购维持增长（如思科收购 Linksys/Flip 是灾难）。

## 七、揭开财务伪装（第8章，财务排雷）

**卡片 7.1 六个危险信号（Red Flags）**
1. 衰退中的现金流（利润涨但经营现金流转差）。
2. 连续的非经常性费用（频繁"一次性"减值/重组粉饰）。
3. 连续的收购（用收购掩盖主业疲弱）。
4. 首席财务官或审计师离开公司。
5. 没有收到货款的账单（应收账款异常）。
6. 变更赊销付款条件和应收账款（放松信用期虚增销售）。

**卡片 7.2 要密切注意的七个其他缺陷**
1. 研发费用化 vs 资本化（资本化虚增当期利润）。
2. 存货增长 > 营收增长（滞销）。
3. 应收账款增长 > 营收增长（激进确认收入）。
4. 预付款项异常膨胀。
5. 养老金缺口。
6. 表外负债（特殊目的实体、担保）。
7. 避税手段/激进会计估计变更。
- 补充（A股适用）：控股股东高比例质押、资金占用、频繁关联交易、审计意见非标、商誉占净资产过高、频繁变更会计师事务所、存贷双高——直接降权或排除。

## 八、估值（第9–10章）

**卡片 8.1 估值基础**
- 按估值全价买入很难投资成功；使用多种估值方法交叉验证更明智。
- 估值是区间不是精确数字：只判断高估/合理/低估三状态。"宁可模糊的正确，不要精确的错误"。
- 对收益说"是"：估值要基于真实盈利能力（现金流），而非表面会计利润。

**卡片 8.2 市盈率（PE）陷阱**
- PE 反映市场情绪不是企业价值。高 PE 可能是成长预期也可能是泡沫；低 PE 可能是价值洼地也可能是价值陷阱。
- 低 PE + 低 ROE = 通常只是平庸公司。更优组合：PE 不一定最低 + ROE 长期 10–15%+ + ROIC 高于融资成本 + 毛利率稳定 + 资产负债表干净。
- 银行不能因 4–6 倍 PE 就认为便宜（利润有会计平滑，要看资产质量/净息差/不良生成率/拨备）。

**卡片 8.3 市净率（PB）/ PEG**
- PB 适合金融、周期股（看净资产质量）。
- PEG = PE/盈利增速，≈1 较合理；但增速可持续性难判。

**卡片 8.4 现金流折现（DCF）**
- 最核心的绝对估值法：算未来自由现金流的现值。
- 适合护城河深厚、盈利稳定的龙头；不适合平庸/周期公司。
- 折现率按护城河与负债率调整（晨星基准约 10.5%）。
- 永续增长率标准 3%，衰退行业 2%。

**卡片 8.5 安全边际**
- 定义：市价与保守估值的差值。只在明显低于内在价值时买，给判断错误留缓冲。
- 经验参考值（公开笔记提炼，非原书硬编码）：优质企业预留 20–30% 折价；周期企业预留 50%+ 折价；杜绝溢价买入。
- 护城河延长高回报再投资窗口 → 宽护城河公司即使 PE 略高（如30倍）若仍有再投资跑道也常值得；现金牛公司（如味好美）不能给太高倍数。

**卡片 8.6 不同类型公司用不同估值法**
- 银行：PB、ROE、不良率、拨备覆盖率、净息差、核心一级资本。
- 保险：PEV、NBV 增长、投资收益率、偿付能力。
- 周期股：PB、吨盈利、行业供需、库存周期、正常化利润。
- 消费股：PE、自由现金流、品牌力、渠道库存、提价能力。
- 制造业：ROIC、订单、毛利率、资本开支、现金流。
- 医药股：研发管线、集采影响、销售费用率、现金流。
- 红利股：股息率、分红率、自由现金流覆盖倍数、负债率。

## 九、十分钟测试（第12章，快速质量考验）

**卡片 9.1 原题清单（用于判断是否值得深入调研）**
1. 公司能否通过一个最小的质量考验？
2. 公司一直不断地赚取营业利润吗？
3. 公司能从经营活动中持续不断地产生现金流吗？
4. 净资产收益率（ROE）能保持 10% 以上，并且有合理的财务杠杆吗？
5. 盈利增长是协调一致还是飘忽不定？
6. 资产负债表有多清白（债务水平/表外负债）？
7. 这家公司产生自由现金流吗？
8. 还有多少"其他"（利润表中的杂项/一次性项目）？
9. 发行在外的股票数量在过去几年明显增长了吗（稀释股东）？
- 用法：多数问题答"否" → 不值得花精力深研，直接过滤。

## 十、行业特征精选（第14–26章）

**卡片 10.1 消费服务业（餐饮/零售）**
- 护城河常来自品牌 + 规模 + 选址；看同店增长、翻台率、现金流稳定、抗周期。

**卡片 10.2 医疗保健（医药/生物/器械/医保）**
- 医药护城河 = 专利 + 特许经营；仿制药靠成本；生物科技看管线；医保组织看规模与用户粘性。
- 警惕：专利悬崖、集采、研发失败。

**卡片 10.3 银行业**
- 重风控、资产质量、不良率、监管；规避高杠杆风险。看 ROE、拨备、净息差。
- 护城河 = 低成本存款基础 + 规模 + 转换成本（账户绑定）。

**卡片 10.4 软件业**
- 护城河常来自高转换成本 + 网络效应（企业软件锁定）；看经常性收入、留存率。

**卡片 10.5 硬件/科技业**
- 技术护城河最短命（迭代快）；真壁垒在标准锁定/生态。警惕高估值与技术迭代。

**卡片 10.6 周期行业（能源/原材料/工业）**
- 重低谷反转、供需格局；严禁高位追高、低位死扛。低谷布局、高峰离场。

**卡片 10.7 公共事业**
- 监管壁垒 + 稳定现金流；增长慢但确定性高，类似债券属性。

## 十一、核心指标阈值速查（经验参考值，公开笔记提炼）

| 指标 | 经验阈值（健康/有护城河信号） | 说明 |
|---|---|---|
| FCF / 销售收入 | > 5% | 真金白银剩下来 |
| 净利润率 | 持续 > 15% | 每卖100块净落袋 |
| ROE | 持续 > 15% 且稳定 | 股东资本回报；靠杠杆的高ROE危险 |
| ROA | 持续 > 6%~7% | 资产运转效率 |
| ROIC vs WACC | ROIC > WACC | 创造价值的门槛 |
| 流动比率 | > 1.5 | 短期偿债（行业可调） |
| 利息覆盖倍数 | > 5× | 盈利覆盖利息 |
| 毛利率趋势 | 稳定或提升 | 定价权体现 |

> 关键：不是看某一年达标，而是**多年连贯达标**。飘忽不定的高数字 = 可能周期/运气/会计花招。
