# grr-qa · 股市真规则问答 Skill

> 把《股市真规则》（晨星 · 帕特·多尔西）蒸馏成**知识问答引擎**：问一个投资概念，用书中方法论作答，每条结论标注来源章节。**只讲方法、不荐个股。**

---

## 这是什么

一个 WorkBuddy / Agent 可直接调用的 skill。它不做取数、不出买卖建议，而是把《股市真规则》的价值投资框架变成一张"概念卡片库"，用来回答：

- 护城河到底是什么？真护城河 vs 伪护城河
- 安全边际怎么理解、市盈率低就能买吗
- 财报里哪些信号是"财务伪装"
- 十分钟测试到底测哪几项
- 管理层怎么看、不同行业怎么估值

每个回答都会标注 `（出自第 X 章 · 概念名）`，可溯源、不编造。

## 文件结构

```
grr-qa/
├── SKILL.md                 # skill 定义：流程、触发词、合规边界、零编造机制
├── references/
│   └── knowledge_base.md    # 概念卡片全集（12 节，覆盖全书 Part I 框架）
└── output-demo.html         # 四种黑金风 HTML 输出形态预览（知识点卡/问答卡/对比表/系列长图）
```

## 安装 / 使用

**方式一：放入 WorkBuddy skills 目录（推荐）**

```bash
cp -r grr-qa ~/.workbuddy/skills/grr-qa
```

放入后，对话中提到"股市真规则 / 晨星护城河 / 安全边际 / 十分钟测试"等即会触发。

**方式二：直接用 LLM 读取**

打开 `SKILL.md` 与 `references/knowledge_base.md`，让模型按 SKILL.md 的"工作流程"用知识库作答即可，无需任何脚本或 API。

## 输出形态（可选 HTML）

`output-demo.html` 演示了四种黑金风可视化，可作为小红书配图：

1. 单张知识点卡 — 一个概念一图流
2. 问答对卡片 — 问题 + 回答 + 出处标签
3. 对比表卡 — 真 vs 伪护城河、清单核对
4. 系列长图 — 多个概念串成一篇投教图文

## 合规边界

- 本 skill **只讲投资方法论**，不评价任何具体个股的买卖。
- 遇到"XX 股票该买吗"等个股决策问题，引导用户用个股分析类工具做研究，本 skill 不作答。
- 所有输出默认附带："以上内容基于《股市真规则》方法论整理，仅供学习研究，不构成投资建议。"
